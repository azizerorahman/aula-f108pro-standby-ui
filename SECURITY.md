# Security

Never post credentials, private device paths, serial numbers or raw account/system inventories in an issue.

Use GitHub's private vulnerability reporting feature on the repository's Security tab for security-sensitive findings. Include the affected source revision, a minimal reproduction and the potential impact. Do not include third-party firmware binaries.

This experimental project has no guaranteed response SLA. Its display and updater code operates on physical hardware; a transfer receipt is not a recovery guarantee or complete security review.
