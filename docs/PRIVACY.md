# Repository privacy

This repository is assembled from an explicit allowlist of source, project-generated assets and public reference material.

It excludes session transcripts, SSH scripts, secrets, account passwords, private hostnames, local network addresses, user directory paths, HID instance paths, serial numbers, raw installation receipts, recordings and vendor executables/firmware binaries.

Comparison images use clean screen artwork. Published PNG/GIF exports carry no source recording metadata, desktop context or device identifiers. Dates and battery values in renders are examples.

Commit attribution uses the requested public GitHub handle and a GitHub noreply address. Required public third-party authorship and license notices are retained.

Do not attach unredacted system inventories or raw HID logs to issues. Runtime install results are written under ignored `private/`; review them before sharing.
