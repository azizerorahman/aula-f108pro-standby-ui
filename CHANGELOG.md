# Changelog

## 0.1.0 — initial public source snapshot

- Standby clock with English/Chinese dates and a blinking accent colon.
- Square icon menus with focus rings and segmented navigation.
- Centred Connection, System, Colour, Brightness, Speed, Volume and Language layouts.
- Original lighting thumbnails restored in native Static-to-LED-Off order.
- Cooperative LCD queue correction and full-frame Connection/Effect rendering.
- Reproducible byte-patch build, clean artwork sources and offline preview.
- Public privacy exclusions, third-party notices and before-and-after comparison.

This is an experimental source snapshot, not a broadly verified prebuilt firmware release. Latest physical effect/flicker acceptance remains pending.
